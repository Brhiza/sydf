# 时月东方设计系统

页面业务样式仍放在原组件或 `styles.css`，所有跨页面共享的视觉规则只放在这里。

## 规则

- 颜色、字号、间距、圆角、阴影、控件高度和页面宽度只在 `tokens.css` 定义。
- 页面宽度只使用 `reading`、`standard`、`wide`、`immersive` 四档，不在业务页面写新的 `max-width`。
- 新按钮和表单优先复用 `primitives.css` 中的基础类；已有按钮逐步映射到同一套基础类。
- 页面内的切换统一使用 `UiSegmentedControl`，空状态统一使用 `UiEmptyState`，页面容器统一使用 `UiPageShell`。
- 统一的是页面骨架、控件行为、反馈方式和视觉尺度，不强行统一业务内容：排盘保留高密度表格，灵签保留仪式流程，风水保留画布工作区；这些差异只能出现在共享骨架内部。
- 表单、选择器和弹窗底部的主次操作统一使用 `UiActionBar`；弹窗外壳间距由 `UiDialogShell` 的 `padding` 档位控制，业务组件不再重复写弹窗内边距。
- 常规按钮统一使用 `UiButton` 的 `primary / secondary / ghost / danger` 语义和三档尺寸；常规单行或多行文字输入统一使用 `UiTextField`，业务页面不再自行组合标签、边框、禁用态和错误提示。日期、分段选择、画布与对话发送等特殊控件继续使用各自的专用组件。
- 共享卡片和普通控件外观只允许通过显式的 `ui-*` 基础类接入；不得按案例、设置、合盘等业务类名自动套用外观。业务选择器只能补充页面布局，避免组件嵌套时产生隐形白块和间距覆盖。
- 小六壬、每日一卦、今日运势、传统黄历与居家风水统一使用 `UiToolPage` 模板；工具页顶部由模板内的 `UiToolToolbar` 提供，日期或时辰切换统一使用 `UiDateNavigator`，不在业务页面重复绘制上一项、日期、下一项和回到当前按钮。
- 工具页的主结果区域统一使用 `UiWorkspaceSurface`，保持相同的表面色、边框、圆角、阴影和裁切规则。一个工具页只保留一个主表面，内部内容通过分区线组织，不再嵌套页面级卡片。
- 阅读型结果页统一使用 `UiReadingWorkspace`，首屏固定为 `hero-media / hero-context / hero-summary` 三段：状态图或结果图、专业信息、现代结论。桌面端由模板统一三栏，移动端由模板统一折为“图片＋专业信息、结论独占下一行”，业务页面不得另写首屏列宽和断点。
- 阅读型章节统一使用 `UiReadingSection`，双栏统一使用 `UiReadingGrid`，摘要统一使用 `UiReadingLead`，常规判断与建议条目统一使用 `UiReadingRows`。业务页面只维护卦象、日期、宫位等确实无法通用的内容布局。
- 业务页面不得重写常规阅读条目的字号、行高、分隔线、标记列宽和移动端折行规则；确需新增通用表达时，先扩展共享组件，再由页面传入数据。
- 暗色模式通过令牌自动切换，组件不再单独维护一套硬编码颜色。
- 移动端间距由全局断点收口，业务页面只保留确实与内容结构相关的响应式规则。
- 业务页面不得再定义页面级 `max-width`；确需调整信息密度时，只能变更 `UiPageShell` 的宽度档位。

## 页面宽度

- `reading`：对话、灵签和单列阅读页。
- `standard`：案例、设置、今日运势、小六壬、每日一卦、传统黄历和普通工具页。
- `wide`：排盘、居家风水和信息密集结果页。
- `immersive`：仅用于确实需要超宽画布的特殊工作区。
